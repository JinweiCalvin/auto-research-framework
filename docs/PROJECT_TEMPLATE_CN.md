# 课题档案模板说明

新课题模板只包含跨项目稳定有用的记录，不复制慢病管理或 ICD 编码课题的内容。

- `RESEARCH_BRIEF.md`：问题、受众、已有证据、数据/许可、算力/预算、停止条件和人工判断项。
- `STAGE_STATUS.md`：每一阶段的状态、输入、产物和下一步决策。`complete` 必须指向真实产物。
- `CLAIMS_AND_EVIDENCE.md`：一条主张一行，关联来源、反证、结果文件和当前状态。
- `EXPERIMENT_PLAN.md`：运行前定义数据、基线、指标、消融、失败标准、命令和环境。
- `decisions/`：记录选题、人工审阅、映射冻结、计划变更和是否继续。
- `idea2paper_runs/`：版本化候选故事快照，不覆盖旧轮次。
- `experiments/`：实验 tracker、代码、日志索引和分析汇总。大型运行目录/原始数据不要纳入 Git。
- `paper/`：大纲、稿件、图表源、PDF、引用和 claim audit。

如项目需要伦理审查、临床试验注册、数据访问审批、专家裁决或云端数据处理，应在 brief 和 decisions 中单独列出负责人、状态与时间。模板是提醒结构，不代表审批已经完成。
